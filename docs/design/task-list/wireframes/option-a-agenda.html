Option A: Agenda (revision 1)

The list stays a list of days, in the order the person and Jet share. It opens with four counts that answer "what is overdue, due, in progress and done" and filter the list when tapped, then one add bar for title, day and goal, then each goal's progress. Overdue comes first but shows at most three rows and can be cleared in one action. Each row says in words when a task was started, and its chip moves it in two taps.

Sample date: Thursday 26 November 2026. This file adds three overdue tasks with no goal to the shared sample, to show the Overdue limit. Shapes carry status: empty box = not started, half box = in progress, full box with tick = done. A black chip with "!" = overdue.
